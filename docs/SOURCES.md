# Encounter mechanics used as references

The simulator is original teaching code and uses no Sea of Stars art/assets.

Reference facts used to shape the encounter:

- Elder Mist second encounter: 3,995 HP.
- Sword second encounter: 800 HP.
- Sword disables for 3 turns and returns with 489 HP.
- Second encounter uses Zale and Valere.
- Attacking the main body while the sword is active causes Counter Slash.
- Splash attacks such as Sunball/Crescent Arc aimed at the sword can also damage the body without triggering Counter Slash.
- Second encounter adds Torblado and Thunder; Healing Mist remains a lock-based heal.

Sources:
- https://seaofstars.fandom.com/wiki/Elder_Mist
- https://www.gamerguides.com/sea-of-stars/guide/side-quests/solstice-shrines/where-to-find-the-solstice-shrine-final-door-in-sea-of-stars

Damage values, MP costs, player HP, turn scheduling, and some lock patterns in this teaching simulator
are intentionally normalized rather than reverse-engineered.
